# FACEIT Map Helper

Project page for FACEIT Map Helper, a Chrome extension for Counter-Strike 2 players on FACEIT.
During the map veto it shows how both teams perform on every map, after the pick the map's T/CT
tendency, the ten players on that map and grenade lineups.

Website: https://pere-d.github.io/faceit-map-helper/

Independent fan project, not affiliated with or endorsed by FACEIT or Valve.
